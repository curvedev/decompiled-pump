# Reference interface adaptation

The user selected their existing Reverse Engineered Pump project as the UI and UX reference. Its retained source and live board, launch, network-menu and source-browser interfaces were inspected on 21 October 2026. The layout is adapted under its MIT license, reproduced in `reference-interface-LICENSE.txt`. No reference backend, deployment settings, wallets, credentials, mainnet configuration or REA claims are imported.

Decompiled Pump now follows the reference's slate background, mint accents, system sans-serif and monospace typography, compact top header, bracket navigation, centered introduction, mint search field, sort/order controls and horizontal coin entries. The launch screen follows the experiment heading, image-first form, paired name/ticker inputs, social fields, optional developer buy, advanced details and live preview. The coin screen has a chart and confirmed-fills column beside compact order and progress cards. Mobile layouts collapse into a single column. The source browser displays selected files from this exact build, supports file switching and copying, and links to the full repository download. The curve lab uses the actual independent integer quote calculation without sending transactions.

DEPUMP retains its own name, original mark, dedicated program, fixed economic rules and explicit network labels, with real SOL on the published mainnet frontend and test SOL on development builds. Only verified accounts and recent on-chain fills are shown; listings, volume, returns, holders and USD conversions are not fabricated. REA was not used for DEPUMP. No project token has been launched.

The Board, Your coins and Watchlist tabs preserve existing account filtering and local saved mints. Sorting uses market cap, name or curve progress because the account format has no creation timestamp. The reference's animations control disables interface motion and respects reduced-motion preferences. No remote fonts or analytics are loaded. Unused Geist font source and license from the earlier interface remain in the repository for provenance; the active interface uses the reference's system font stack.

Listings share an in-flight request and a 15-second cache. RPC requests have a 12-second timeout and one retry on HTTP 429. Recent-fill history shares pending requests and caches success for 60 seconds. Explicit refresh refetches. The free public RPC may temporarily fail to return history. Browser verification details are in `research/ui-checks.json`; wallet-extension approvals and physical devices remain untested.
